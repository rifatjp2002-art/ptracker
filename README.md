## 📖 সারসংক্ষেপ (Overview)

**পিরিয়ড ট্র্যাকার (Period Tracker)** একটি মার্জিত, ব্যবহারকারী-বান্ধব এবং সম্পূর্ণ নিরাপদ প্রগ্রেসিভ ওয়েব অ্যাপ (PWA)। এটি বিশেষভাবে নারী স্বাস্থ্য সচেতনতা, সময়মতো পূর্বাভাস, এবং সম্পূর্ণ গোপনীয়তা নিশ্চিত করার জন্য বাংলা ও ইংরেজি উভয় ভাষায় তৈরি।

অ্যাপটির সবচেয়ে বড় সুবিধা হলো এটি **১০০% অফলাইনেও চমৎকারভাবে কাজ করে** এবং আপনার সংবেদনশীল স্বাস্থ্য ডাটা সম্পূর্ণ সুরক্ষিত রাখতে এতে রয়েছে **৪-ডিজিটের পিন ও বায়োমেট্রিক (Fingerprint / Face ID) অ্যাপ লক**। ইন্টারনেট সংযোগ না থাকলেও আপনি সাইকেল ডাটা যোগ করতে পারবেন, ক্যালেন্ডার দেখতে পারবেন, উপসর্গ ট্র্যাক করতে পারবেন এবং ট্রেন্ড অ্যানালিটিক্স গ্রাফ দেখতে পারবেন।

## ✨ নতুন ও মূল বৈশিষ্ট্যসমূহ (Key Features)

### 📊 ১. সাইকেল ট্রেন্ড গ্রাফ ও অ্যানালিটিক্স (Cycle Regularity Visual Chart)
* **গত ৩-৬ মাসের ভিজ্যুয়াল বার চার্ট:** প্রতিটি সাইকেলের শুরু থেকে পরবর্তী সাইকেলের ব্যবধান কতদিন ছিল (যেমন ২৮ দিন, ৩০ দিন) তা রঙিন ইন্টারেক্টিভ বার চার্টে এক পলকে দেখা যায়।
* **সাইকেল রেগুলারিটি স্কোর:** সাইকেল স্বাভাবিক (২১–৩৫ দিন), অনিয়মিত (Irregular), নাকি ছোট/লম্বা তা এমারেল্ড, অ্যাম্বার ও রোজ রঙে হাইলাইট করা হয়।
* **প্রবণতা বিশ্লেষণ (Trend Insights):** গড় সাইকেল দৈর্ঘ্য, সাইকেলের ওঠানামা (Variation) এবং পরবর্তী পিরিয়ডের সম্ভাব্য ব্যপ্তি প্রদর্শন।

### 🔐 ২. প্রাইভেসি ও ৪-ডিজিটের পিন লক (App Privacy & 4-Digit PIN Lock)
* **৪-ডিজিটের পাসকোড সুরক্ষা:** আপনার অনুমতি ছাড়া কেউ অ্যাপ ওপেন করতে পারবে না।
* **ক্রিপ্টোগ্রাফিক হ্যাশিং (SHA-256):** ব্যবহারকারীর পিন সরাসরি সংরক্ষণ না করে ব্রাউজারের `crypto.subtle` এপিআই দিয়ে নিরাপদ হ্যাশ আকারে সংরক্ষিত থাকে।
* **Google দিয়ে ভেরিফাই করে পিন রিসেট (Secure Recovery):** পিন ভুলে গেলে অপরিচিত কেউ যেন খুলতে না পারে, সেজন্য ব্যবহারকারীর নিজস্ব গুগল অ্যাকাউন্ট দিয়ে সাইন-ইন ভেরিফিকেশনের পরই কেবল পিন রিসেট করা সম্ভব।
* **বায়োমেট্রিক সাপোর্ট (Fingerprint / Touch ID / Face ID):** সাপোর্টেড ডিভাইসে WebAuthn প্রযুক্তির মাধ্যমে সরাসরি আঙুলের ছাপ বা ফেস রিকগনিশন দিয়ে তাৎক্ষণিক আনলক।
* **স্মার্ট অটো-লক (Auto-Lock on Background):** অ্যাপ মিনিমাইজ করলে বা অন্য ট্যাবে গেলে স্বয়ংক্রিয়ভাবে অ্যাপ লক হয়ে যায়।
* **ইনস্ট্যান্ট লক বাটন:** হেডার মেনু থেকে এক ক্লিকেই "এখনই লক করুন (Lock Now)" সুবিধা।
* **হ্যাপটিক ফিডব্যাক ও শেক অ্যানিমেশন:** ভুল পিন প্রবেশ করালে ভাইব্রেশন এবং স্মুথ রেড শেক ইফেক্ট।

### 🌗 ৩. অটোমেটিক ডিভাইস থিম ও ডার্ক/লাইট মোড (Theme Modes)
* **ডিভাইস সেটিংসের সাথে সিঙ্ক:** ফোনের অটো ডার্ক বা লাইট মোডের সাথে অ্যাপের ব্যাকগ্রাউন্ড ও কালার প্যালেট স্বয়ংক্রিয়ভাবে খাপ খাইয়ে নেয়।
* **ম্যানুয়াল থিম সুইচার:** হেডার ড্রপডাউন থেকে যেকোনো সময় ৩টি মোডের যেকোনোটি বাছাই করা যায়:
  * 📱 **ডিভাইস (স্বয়ংক্রিয়)** — সিস্টেম প্রেফারেন্স অনুসরণ করে।
  * 🌙 **ডার্ক মোড** — গভীর রাতের ব্যবহারের জন্য চোখ-বান্ধব ডার্ক ইন্টারফেস।
  * ☀️ **লাইট মোড** — মিষ্টি প্যাস্টেল পিঙ্ক ও হোয়াইট ফ্রেশ লুক।

### 📲 ৪. পূর্ণাঙ্গ PWA ও ইন-অ্যাপ ইনস্টলেশন (Progressive Web App)
* **ওয়ান-ক্লিক ইনস্টল:** কোনো অ্যাপ স্টোর ছাড়াই ব্রাউজার থেকে অ্যান্ড্রয়েড, আইফোন বা কম্পিউটারে সরাসরি ইনস্টল করা যায়।
* **হোম স্ক্রিন শর্টকাট ও স্প্ল্যাশ স্ক্রিন:** স্ট্যান্ডার্ড 192x192, 512x512 মাস্কেবল আইকন ও ব্যাকগ্রাউন্ড সহ দেশীয় মোবাইল অ্যাপের অভিজ্ঞতা।
* **আইওএস (iOS) গাইড:** আইফোন/আইপ্যাড ব্যবহারকারীদের জন্য সাফারি ব্রাউজার থেকে সরাসরি ইনস্টল করার স্পষ্ট অ্যানিমেটেড পপআপ গাইড।

### ⚡ ৫. ১০০% অফলাইন সাপোর্ট (Offline-First Architecture)
* **লোকাল ক্যাশিং:** ফায়ারবেস ফায়ারস্টোরের `persistentLocalCache` ও সার্ভিস ওয়ার্কার (`sw.js`) এর সাহায্যে ইন্টারনেট সংযোগ বিচ্ছিন্ন থাকলেও অ্যাপ পুরো গতিতে কাজ করে।
* **অফলাইন স্ট্যাটাস ব্যানার:** ইন্টারনেট চলে গেলে স্ক্রিনে হালকা অফলাইন নোটিফিকেশন ব্যানার দৃশ্যমান হয়।
* **স্বয়ংক্রিয় ক্লাউড সিঙ্ক:** আবার অনলাইন হওয়া মাত্রই লোকাল ডাটা ক্লাউডে নিরাপদে সেভ হয়ে যায়।

### 🧠 ৬. স্মার্ট সাইকেল প্রেডিকশন (Smart Cycle Predictions)
* **পরবর্তী পিরিয়ডের সম্ভাব্য দিন গণনা:** অতীতের পিরিয়ড চক্রের গড় দিন বিশ্লেষণ করে পরবর্তী পিরিয়ডের সময় নিখুঁতভাবে পূর্বাভাস দেয়।
* **ওভিউলেশন ও ফার্টাইল উইন্ডো:** গর্ভধারণের উপযুক্ত সময় ও ডিম্বস্ফোটনের আনুমানিক দিন স্বয়ংক্রিয়ভাবে ক্যালেন্ডারে দেখায়।
* **চক্রের ৪টি পর্যায়:** মেনস্ট্রুয়াল ফেজ, ফলিকুলার ফেজ, ওভিউলেশন ফেজ এবং লিউটিয়াল ফেজ সম্পর্কিত বিশদ স্বাস্থ্য টিপস।

### 🩸 ৭. দ্রুত সাইকেল এন্ট্রি ও লক্ষণ ট্র্যাকিং
* **৩ দিনের দ্রুত প্রেসট বোতাম (Quick Duration Chips):** পিরিয়ড সাধারণত ৩, ৪, ৫, ৬ বা ৭ দিন স্থায়ী হলে ১ ক্লিকেই সিলেক্ট করার চিপস।
* **একক এন্ট্রি সিস্টেম:** প্রতিদিন আলাদা এন্ট্রি দিতে হয় না; শুরুর দিন ও মোট দিন সংখ্যা সিলেক্ট করলেই ক্যালেন্ডার স্বয়ংক্রিয়ভাবে পুরো পিরিয়ড প্রদর্শন করে।
* **ফ্লো ইনটেনসিটি ও উপসর্গ:** হালকা (Light), মাঝারি (Medium), বা ভারী (Heavy) রক্তপ্রবাহ এবং মেজাজ, পেট ব্যথা, ব্রণ, অবসাদ ও ব্যক্তিগত নোটস সংরক্ষণ।

### 🌐 ৮. দ্বিভাষিক ইন্টারফেস (Bilingual: বাংলা ও English)
* এক ক্লিকেই সম্পূর্ণ অ্যাপের ভাষা বাংলা থেকে ইংরেজিতে বা ইংরেজি থেকে বাংলায় রূপান্তর। ব্যবহারকারীর পছন্দের ভাষা স্বয়ংক্রিয়ভাবে সেভ থাকে।

### 🔒 ৯. নিরাপদ গুগল লগইন ও গেস্ট মোড (Guest Mode & Cloud Migration)
* **গেস্ট হিসেবে তাৎক্ষণিক শুরু:** লগইন ছাড়াও সরাসরি গেস্ট মোডে সম্পূর্ণ অ্যাপ ব্যবহার করা যায়।
* **স্বয়ংক্রিয় ক্লাউড মাইগ্রেশন:** পরবর্তীতে গুগল দিয়ে সাইন ইন করলে লোকাল ডাটা কোনো তথ্য না হারিয়ে স্বয়ংক্রিয়ভাবে ক্লাউডে সিঙ্ক হয়ে যায়।

### 🩺 ১০. চিকিৎসকের জন্য PDF / CSV রিপোর্ট (Doctor Consultation Export)
* হিস্ট্রি স্ক্রিন থেকে এক ক্লিকেই বিগত সাইকেলের গড় সময়, সাইকেল নিয়মিত কিনা, রক্তপ্রবাহ এবং উপসর্গসমূহের একটি মার্জিত **A4 প্রিন্টেবল PDF রিপোর্ট** বা **CSV ফাইল** ডাউনলোড করা যায়।

### 💧 ১১. দৈনিক সুস্থতা চেকলিস্ট ও নোটিফিকেশন (Daily Wellness & Habit Tracker)
* প্রতিদিন ৮ গ্লাস পানি পানের ট্র্যাকার (Water Tracker), আয়রন বা জন্মনিয়ন্ত্রণ পিল খাওয়ার চেকলিস্ট এবং মেজাজ (Mood) নির্বাচনের সহজ উইজেট।
* পরবর্তী সম্ভাব্য পিরিয়ডের ১ বা ২ দিন আগে ব্রাউজারে নোটিফিকেশন অ্যালার্ট।

> ১. যেদিন আপনার পিরিয়ড শুরু হবে, ক্যালেন্ডারে বা `+` বাটনে চাপ দিয়ে **শুধুমাত্র শুরুর ১ম দিনটি** নির্বাচন করুন।
> ২. স্থায়িত্বের ঘরে দ্রুত সিলেক্ট চিপস (যেমন ৩ দিন বা ৪ দিন) চাপুন অথবা নিজের মতো দিন দিন। ক্যালেন্ডারে পুরো সময়টি স্বয়ংক্রিয়ভাবে মার্ক হয়ে যাবে।
> ৩. যদি পিরিয়ডের দিন বাড়ে (যেমন ৩ দিনের জায়গায় ৫ দিন হয়), তবে নতুন এন্ট্রি না দিয়ে **প্রথম দিনের এন্ট্রিটিতে ক্লিক করে দিন সংখ্যা ৩ থেকে বাড়িয়ে ৫ করে সেভ করুন**। 
> ৪. এতে আপনার অতীতের এন্ট্রিগুলো ক্লিন থাকবে এবং ট্রেন্ড গ্রাফ ও প্রেডিকশন অ্যালগরিদম একদম নিখুঁত কাজ করবে।

## 🛠️ প্রযুক্তি কাঠামো (Tech Stack)

- **Frontend Core:** [React 19](https://react.dev/), [TypeScript](https://www.typescriptlang.org/)
- **Build Tool:** [Vite 6](https://vitejs.dev/) with `@tailwindcss/vite`
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Offline & PWA:** `vite-plugin-pwa`, Service Worker (`sw.js`), Web App Manifest
- **Security:** SHA-256 Web Cryptography API, WebAuthn API (Fingerprint/Biometrics)
- **Backend & Auth:** [Firebase v12](https://firebase.google.com/) (Google Authentication & Cloud Firestore with offline cache)
- **Reporting:** HTML5 Canvas, SVG Bar Charts & Print Engine

## 🚀 লোকাল সেটআপ ও রান করার নির্দেশিকা (Getting Started)

### ১. রিপোজিটরি ক্লোন করুন (Clone repository):
```bash
git clone https://github.com/your-username/period-tracker-pwa.git
cd period-tracker-pwa
```

### ২. ডিপেন্ডেন্সি ইনস্টল করুন (Install dependencies):
```bash
npm install
```

### ৩. ফায়ারবেস কনফিগারেশন (Configure Firebase):
`firebase-applet-config.example.json` ফাইলটিকে `firebase-applet-config.json` নামে কপি করুন অথবা আপনার নিজস্ব ফায়ারবেস প্রজেক্টের ক্রিডেনশিয়াল বসিয়ে দিন:

```json
{
  "projectId": "your-project-id",
  "appId": "your-app-id",
  "apiKey": "your-api-key",
  "authDomain": "your-project-id.firebaseapp.com",
  "firestoreDatabaseId": "(default)",
  "storageBucket": "your-project-id.firebasestorage.app",
  "messagingSenderId": "your-sender-id"
}
```

> **টিপ:** আপনি ফায়ারবেস কনসোলে গিয়ে **Authentication** (Google Provider) এবং **Cloud Firestore** ডাটাবেজ সক্রিয় করে নিবেন।

### ৪. ডেভেলপমেন্ট সার্ভার চালু করুন (Run locally):
```bash
npm run dev
```
ব্রাউজারে `http://localhost:3000` ওপেন করুন।

### ৫. প্রোডাকশন বিল্ড তৈরি করুন (Build for production):
```bash
npm run build
```
বিল্ড ফাইলগুলো `dist/` ফোল্ডারে তৈরি হবে।
